LNote

Documents and notes, in one place.

Keep your materials together

Organize documents and Markdown notes. On macOS, index supported PDF, HWP/HWPX, Word, Excel, PowerPoint and text files to search your materials.

Ask and check the source

Ask about selected materials, review source excerpts and save an answer with its references as a note. Check the original document when accuracy matters.

Choose how to process your documents

Use an available on-device/local model or connect a supported external AI service with your own API key. External requests send relevant inputs to that provider and may incur separate charges.

Back up your work

LNote for macOS can back up notes, conversations, settings and document knowledge databases. Store backups privately.

자료 정리

문서와 Markdown 노트를 함께 관리합니다. macOS에서는 지원되는 PDF, HWP/HWPX, Word, Excel, PowerPoint 및 텍스트 문서를 색인하여 검색할 수 있습니다.

질문과 출처 확인

선택한 자료에 질문하고 원문 발췌를 확인합니다. 답변과 출처를 노트로 저장해 정리를 이어갈 수 있습니다. 중요한 내용은 원문을 함께 확인하세요.

처리 방식 선택

사용 가능한 기기 내·로컬 모델을 쓰거나, 본인의 API 키로 지원되는 외부 AI 서비스를 연결할 수 있습니다. 외부 요청은 관련 입력을 해당 제공자에게 전송하며 별도 이용 요금이 발생할 수 있습니다.

백업

macOS 버전에서는 노트, 대화, 설정과 문서 지식 데이터베이스를 백업할 수 있습니다. 백업 파일도 개인 자료로 관리하세요.
