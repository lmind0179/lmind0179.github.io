LNote Support

Contact, troubleshooting and license guidance

Contact

Email lmind0179@gmail.com with your platform (macOS, Windows, iOS, or Android), OS version, app version, the steps you took and the error message. Do not send API keys, license tokens or confidential documents. A redacted screenshot or text example is sufficient.

Windows license registration and seat transfer (Up to 3 PCs)

A single LNote Windows Paid license key allows concurrent activation on up to 3 PCs. Once activated online once, the application continues to operate offline.

When replacing or upgrading a PC, you can release the registered seat on your current PC via Settings → Info → "Release License for this PC..." or the tray menu. After releasing, you can immediately register your key on a new PC. All documents, notes, and local chats remain intact. If a computer was formatted, lost, or broken before deregistration, contact lmind0179@gmail.com with your order number or purchase email, and our team will remotely unbind the seat for you.

Documents do not appear in results

Ensure that you selected the intended folder or database and that indexing has completed. Scanned PDFs without OCR or password-protected files cannot be read. Re-index any files that were modified outside LNote.

External AI requests and billing

Check the selected provider and model, network connectivity, API key validity, and account quotas. External AI API usage fees are billed separately by each AI provider (OpenAI, Google, Anthropic) according to their own pricing models and are not included in the one-time app purchase price. Never send your API keys by email.

Local models and remote access

On-device models (such as Gemma and bge-m3) process queries completely offline on your device without incurring API fees. If using a custom local or remote Ollama server, ensure the server is running at the configured address. Configure Telegram remote access only when needed, and safeguard your bot token.

Backup, data preservation and privacy

Before restoring, preserve a backup copy of your current notes and knowledge bases. Deleting an index does not erase your original documents or exported files. See the Privacy Policy for full data retention and deletion details.

Windows 정품 라이선스 등록 및 기기 이전 (최대 3대)

LNote Windows 유료 라이선스 1개는 **최대 3대의 PC에서 동시에 등록**하여 사용할 수 있습니다. 최초 1회 온라인 정품 인증이 완료되면 이후에는 인터넷 연결 없이도 오프라인에서 안전하게 작동합니다.

PC를 교체하거나 다른 컴퓨터로 이전할 경우, 기존 PC의 [환경설정 → 정보] 탭 또는 시스템 트레이 메뉴에서 '이 PC 라이선스 해제...' 버튼을 클릭하면 등록 좌석이 즉시 반환됩니다. 반환 후 새 PC에서 동일한 라이선스 키를 바로 등록할 수 있으며, PC에 저장된 기존 문서와 노트 데이터는 안전하게 보존됩니다. 만약 컴퓨터 고장이나 갑작스러운 포맷 등으로 직접 등록을 해제하지 못하신 경우, 구매자 이메일 또는 주문번호와 함께 고객지원팀(lmind0179@gmail.com)으로 문의해 주시면 원격으로 기기 등록 해제를 지원해 드립니다.

문서가 검색되지 않을 때

선택한 작업 폴더 또는 데이터베이스가 맞는지, 색인이 완료되었는지 확인하세요. 글자 정보가 없는 이미지 스캔 PDF나 암호가 걸린 문서는 텍스트 추출이 불가능합니다. 외부에서 원본 파일을 수정한 경우 재색인을 실행해 주세요.

외부 AI 연결 오류 및 이용 요금 안내

선택한 AI 제공자(OpenAI, Google Gemini, Anthropic), 인터넷 연결 상태, API 키 유효성, 각 제공사 계정의 크레딧 잔액을 확인하세요. 외부 AI API 사용료는 앱 구매 가격과 별개로 각 AI 회사 정책에 따라 사용자 계정에 직접 부과됩니다. 문의 시 API 키를 절대 메일에 포함하지 마세요.

온디바이스 AI 및 원격 접속

온디바이스 모델(Gemma, bge-m3)은 인터넷 연결 없이 기기 내부에서 완전 오프라인으로 작동하며 추가 요금이 전혀 발생하지 않습니다. 로컬 또는 원격 Ollama 서버를 사용할 경우 설정한 주소에서 서버가 정상 실행 중인지 확인하세요. 텔레그램 연동은 원격 조회가 필요할 때만 설정하고 봇 토큰 관리에 유의하세요.

백업 및 데이터 보호

백업 복원 전에는 현재 작업 중인 노트와 지식베이스 사본을 안전한 곳에 먼저 보관하세요. 색인을 삭제하더라도 원본 문서나 내보낸 노트 파일이 삭제되지는 않습니다. 자세한 데이터 처리 원칙은 개인정보 처리방침을 참고하세요.
