LNote Support

Contact and troubleshooting

Contact

Email lmind0179@gmail.com with your platform, OS version, app version, the steps you took and the error message. Do not send API keys, bot tokens or private documents. A redacted example is usually enough.

Documents do not appear in results

Check that you selected the intended folder or database and that indexing completed. Scanned or encrypted PDFs may not provide extractable text. A document changed after indexing may need to be indexed again.

An external AI request fails

Check the selected provider and model, network access, API key validity, provider quota and billing. API usage charges are separate from the app purchase. Do not email your key.

Local models and remote access

For local-server use, check that the server is running at the configured address and the model is available. A remote address sends request content to that server. Configure Telegram only if you want remote access, and protect the bot token and allowed user ID.

Backup and privacy

Before restoring, keep a separate copy of your current data and backup. Deleting an index does not remove every original or exported copy. See the privacy policy for storage and deletion choices.

문의 및 문제 해결

문의

lmind0179@gmail.com으로 사용 플랫폼, 운영체제 버전, 앱 버전, 실행한 순서와 오류 메시지를 보내 주세요. API 키, 봇 토큰 및 개인 문서는 보내지 마세요. 개인정보를 가린 예시로도 확인할 수 있습니다.

문서가 검색되지 않을 때

선택한 폴더와 데이터베이스가 맞는지, 색인이 완료되었는지 확인하세요. 스캔 문서나 암호화된 PDF는 텍스트 추출이 어려울 수 있습니다. 색인 후 원문을 수정했다면 다시 색인해야 할 수 있습니다.

외부 AI 요청이 실패할 때

선택한 제공자·모델, 인터넷 연결, API 키 유효 여부, 제공자 할당량과 결제 상태를 확인하세요. API 이용 요금은 앱 구매 비용과 별개입니다. 문의에 API 키를 포함하지 마세요.

로컬 모델 및 원격 접속

로컬 서버를 사용한다면 설정한 주소에서 서버가 실행 중인지, 모델을 사용할 수 있는지 확인하세요. 원격 주소를 지정하면 해당 서버로 요청 내용이 전송됩니다. 텔레그램은 원격 접속이 필요할 때만 설정하고, 봇 토큰과 허용 사용자 ID를 보호하세요.

백업 및 개인정보

복원 전에 현재 데이터와 백업의 사본을 별도로 보관하세요. 색인 삭제가 모든 원본·내보낸 사본을 삭제하지는 않습니다. 저장·삭제 방법은 개인정보 처리방침에서 확인할 수 있습니다.
