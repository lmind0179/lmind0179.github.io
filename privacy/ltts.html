LTTS Privacy Policy

Last updated: November 15, 2026

1. On-device Processing & Local Storage

LTTS prioritizes local on-device processing. Source documents, input text, voice-cloning reference recordings, and generated audio are processed directly on your local computer and stored in your desktop storage. Developers do not collect or monitor your manuscripts or private recordings.

  • Voice Cloning: Reference recordings and clone profiles are stored exclusively on your device and are never uploaded to developer servers. Explicit user confirmation of voice ownership is required before profile registration.
  • Mobile Clients: iOS and Android applications connect to your desktop PC backend. iOS audio downloads create a local copy on the device. Android uses the camera solely for pairing QR code scanning and does not save scanned camera images.

2. External AI Cloud Services & Cross-border Data Transfer

When you explicitly select cloud-based analysis or cloud synthesis engines, or enter third-party API keys, the necessary text is transmitted to external providers in the United States under secure HTTPS encryption.

Recipient Country Data Transferred Purpose Retention Period
Google LLC (Gemini API) USA Text for context analysis Context analysis and punctuation refinement Per Google account & billing terms (Do not submit sensitive data to unpaid tiers)
OpenAI Inc. (API) USA Text for context analysis Context analysis and prosody refinement Per OpenAI Business API terms (Not used to train models)
Anthropic PBC (Claude) USA Text for context analysis Context analysis and structure breakdown Per Anthropic Commercial terms
Microsoft Corp. (Azure Speech) USA Text for speech synthesis High-quality neural speech synthesis Per Microsoft Azure Commercial terms

API keys are saved in macOS Keychain or desktop session memory and are never transmitted to LTTS developer servers.

3. User Consent & Refusal Rights

LTTS prompts a mandatory Terms of Service & Privacy Consent dialog on the first application launch across all supported platforms. If you decline consent to external cloud data transmission, you can fully utilize offline local engines (Supertonic 3, VoxCPM2, Kokoro-82M) without sending any text outside your device.

4. Connections, Remote Relay & Activation

When remote access is enabled through a relay server, connection requests and audio streaming pass through LMind's secure relay infrastructure (utilizing Cloudflare edge and Oracle Cloud). No input text or generated audio files are ever stored on the relay server; data is streamed in real-time under end-to-end encryption (AES-256-GCM) and discarded immediately upon transmission. The relay server records only transient connection hashes, device identifiers, platform info, and bandwidth volume for abuse prevention. Paid Windows activation verifies purchase keys and desktop hardware hashes against the activation registry. Apple iCloud auto-connect syncs pairing metadata via your private iCloud database.

5. Data Deletion & Privacy Rights

You can permanently delete manuscripts, audio jobs, and voice cloning profiles at any time directly in the desktop Library and Voice Manager. For inquiries regarding server activation records or rights to access, rectification, or erasure, please contact LMind Support.

6. Data Protection Officer & Inquiries

To ensure personal data protection and resolve related complaints, the operator designates the following contact:

  • Organization: LMind Customer Support & Privacy Team
  • Email: lmind0179@gmail.com
  • Scope: Personal data inquiries, erasure requests, activation record verification, and Terms compliance.

LTTS 개인정보 처리방침

최종 개정일: 2026년 11월 15일

1. 기기 로컬 처리 및 데이터 보관 원칙

LTTS는 기기 내부 로컬 처리를 기본으로 동작합니다. 사용자가 입력한 설교 및 문서 원문, 음성 복제용 녹음 파일, 합성된 오디오 결과물은 연결된 사용자의 컴퓨터/기기에 직접 저장·처리됩니다. 개발자는 사용자의 원문이나 사적인 녹음을 임의로 수집하거나 열람하지 않습니다.

  • 음성 복제(내 목소리) 데이터: 음성 복제에 사용되는 녹음 파일과 모델 가중치는 사용자의 기기 내부 보관함에만 저장되며 외부 개발사 서버로 업로드되지 않습니다. 프로필 등록 전 본인 음성 확인 동의가 필수로 요구됩니다.
  • 모바일 기기 연동: iOS 및 Android 앱은 사용자의 PC 백엔드와 통신합니다. iOS 음원 다운로드는 기기에 별도 로컬 사본을 생성합니다. Android 카메라는 PC 연결 QR 스캔에만 사용되며 스캔 이미지를 파일로 저장하지 않습니다.

4. 연결, 중계 서버 및 정품 활성화

외부 연결(원격 생성 및 모바일 재생) 기능을 활성화하는 경우, 연결 요청과 오디오 스트리밍 데이터가 LMind가 운영하는 보안 중계 인프라(Cloudflare 글로벌 엣지 및 Oracle Cloud)를 경유합니다. 사용자가 입력한 문서 원문 및 생성된 음성 데이터는 중계 서버에 일체 보관되지 않으며, 기기간 종단간 암호화(AES-256-GCM) 상태로 실시간 스트리밍된 후 즉시 소멸(휘발)합니다. 중계 서버는 어뷰징 방지 및 트래픽 관리를 위해 등록 토큰 해시, 기기 인증 식별자, 플랫폼, 월별 전송량만을 최소한으로 집계합니다. Windows 판매판 정품 활성화는 구매 키와 PC 파생 하드웨어 식별값을 인증 서버로 전송합니다. Apple iCloud 자동 연결은 Apple 개인 iCloud 데이터베이스를 통해 동기화됩니다.
