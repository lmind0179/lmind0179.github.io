LTTS Privacy Notice

Synthesis and storage

LTTS processes submitted documents and text, voice-cloning recordings, generated audio, and job settings on the connected computer. iOS downloads create a separate copy on the device. Android uses the camera to scan pairing QR codes and does not save scan images as files.

Online services

Depending on desktop settings, Gemini, OpenAI, or Claude receives text for analysis, and Gemini, Azure Speech, or Microsoft Edge receives text for synthesis. API keys authenticate provider requests. macOS uses the Keychain, and Windows uses backend session memory. Do not submit sensitive, confidential, or personal information to unpaid Gemini services. Gemini · OpenAI · Anthropic · Azure Speech · Microsoft Edge

Connections and activation

Requests and responses sent to a remote address pass through the relay. Relay registration uses an activation code or Apple purchase verification information, device authentication, a name, platform, and registration status. The relay accounts for monthly data usage. Paid Windows activation sends the purchase key, a computer-derived identifier, and device authentication data. iCloud auto-connect syncs connection data through Apple iCloud.

Deletion and contact

Delete jobs and reference recordings in the desktop library and voice manager. Delete mobile downloads and exported files separately where they are stored. Contact LMind Support for access, correction, deletion, restriction, or questions about server registration records.

LTTS 개인정보 처리 안내

음성 생성 및 보관

LTTS는 사용자가 입력한 문서와 텍스트, 음성 복제용 녹음, 합성 결과와 작업 설정을 연결된 PC에서 처리합니다. iOS의 음원 다운로드는 기기에 별도 사본을 만듭니다. Android 카메라는 PC 연결 QR을 읽으며 앱은 스캔 이미지를 파일로 저장하지 않습니다.

온라인 서비스

PC 설정에 따라 Gemini·OpenAI·Claude에는 분석 대상 텍스트가, Gemini·Azure Speech·Microsoft Edge에는 합성 대상 텍스트가 전송됩니다. API 키는 제공자 인증에 사용되며 macOS에서는 키체인, Windows에서는 백엔드 세션 메모리에 보관됩니다. Gemini 무상 서비스에는 민감정보·기밀정보·개인정보를 보내지 마세요. Gemini · OpenAI · Anthropic · Azure Speech · Microsoft Edge

연결 및 활성화

외부 주소의 연결 요청과 응답은 중계 서버를 통과합니다. 중계 등록에는 등록 코드 또는 Apple 구매 검증 정보, 기기 인증값, 이름, 플랫폼과 등록 상태가 사용됩니다. 중계는 월별 전송량을 집계합니다. Windows 판매판 활성화는 구매 키와 PC 파생 식별값, 기기 인증값을 전송합니다. iCloud 자동 연결을 사용하면 연결 정보가 Apple iCloud로 동기화됩니다.

삭제 및 문의

작업과 등록 음성은 PC의 보관함과 목소리 관리에서 삭제할 수 있습니다. 기기의 다운로드와 내보낸 파일은 저장 위치에서 별도로 삭제합니다. 열람·정정·삭제·처리 정지 및 서버 등록 정보 문의는 LMind 고객 지원으로 접수합니다.
