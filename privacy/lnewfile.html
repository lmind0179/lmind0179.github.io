Privacy Policy for LNewFile

Effective Date: October 27, 2026

1. Operator and scope

LNewFile is a macOS Finder extension and popup file creation utility provided by lmind. This Privacy Policy outlines file creation, Finder automation, popup positioning event detection, template storage, and support inquiries. Developer contact: lmind0179@gmail.com.

2. Developer collection and tracking

LNewFile does not collect, scan, transmit, or monetize your file contents, file names, folder paths, keystrokes, or diagnostic usage data to developer servers. The App operates without user accounts, advertising SDKs, tracking pixels, or third-party telemetry frameworks. If you contact support by email, we receive your email address and message solely to respond to your technical question.

3. Popup placement and mouse event monitoring

The automatic popup uses mouse events and window geometry as follows:

  • Mouse clicks and window position: The app detects left and right mouse clicks and reads Finder popup window geometry to display, position, and dismiss the file creation popup. The popup is displayed while Finder is the active app.
  • Keyboard input: The app does not monitor keyboard events or record keystrokes, passwords, or typed text.
  • Permission: The automatic popup requires Input Monitoring permission. You can grant or revoke it in System Settings > Privacy & Security > Input Monitoring.

4. Finder integration and Apple Events automation

When you request a new file, LNewFile sends Apple Events to Finder (com.apple.finder) to identify the destination. It queries the clicked or selected item's type and path, the current insertion location, or the Desktop location. These Finder queries do not read or analyze the contents of existing files. Finder Automation permission allows destination lookup; file creation uses separately authorized folder access.

5. Sandboxed file creation and target storage

LNewFile creates empty or template-based files strictly within folder paths authorized by you using Apple's standard Security-Scoped Bookmarks:

  • Files are written directly to your local file system drive. No folder structures or file paths are ever uploaded to developer servers.
  • If you choose a target folder located on Apple iCloud Drive, an external drive, or a third-party synchronization directory (such as Dropbox or Google Drive), file persistence and network synchronization are governed by that storage provider's service policies.

6. Template management and local storage

Custom templates, settings, and folder access bookmarks are stored in the app's storage on your Mac. Adding a template copies the document into that storage. Some local data may remain after the app is removed. Files you have created remain in their destination folders and can be managed or deleted in Finder. Contact lmind0179@gmail.com for instructions on removing local app data.

7. User controls and support retention

You can remove custom templates and saved folder authorizations in the app. You can revoke Input Monitoring and Finder Automation permissions in System Settings > Privacy & Security. The developer cannot remotely access or delete files on your Mac. Support emails sent to lmind0179@gmail.com are used to respond to your inquiry, retained while needed for that purpose, and deleted when no longer needed. You can request deletion of support correspondence by email.

8. Changes to this policy

Any updates to this policy will be posted on this public page along with an updated effective date.

LNewFile 개인정보 처리방침

시행일: 2026년 10월 27일

1. 운영자 및 적용 범위

LNewFile은 lmind가 개발·제공하는 macOS Finder 확장 및 마우스 팝업 새 파일 생성 유틸리티입니다. 본 개인정보 처리방침은 파일 생성, Finder 자동화, 팝업 창 배치를 위한 이벤트 감지, 서식 템플릿 보관, 그리고 고객 지원에 관한 사항을 설명합니다. 개발자 문의: lmind0179@gmail.com.

2. 개발자의 수집 및 추적 미수행

LNewFile은 생성된 파일의 내용, 파일명, 폴더 경로, 키보드 입력 내용, 사용자 이용 통계를 개발자 서버로 전송하거나 수집하지 않습니다. 회원가입이나 계정 시스템을 운영하지 않으며, 광고 모듈이나 제3자 분석 SDK를 일체 포함하지 않습니다. 이메일 문의 시 제공해주신 이메일 주소와 문의 내용은 고객 응대 목적으로만 한정하여 처리됩니다.

3. 팝업 배치 및 마우스 이벤트 감지

자동 팝업은 다음과 같이 마우스 이벤트와 창 위치 정보를 사용합니다:

  • 마우스 클릭과 창 위치: 좌우 마우스 클릭을 감지하고 Finder 팝업의 창 위치 정보를 읽어 새 파일 팝업을 표시·배치하거나 닫습니다. 팝업은 Finder가 활성화된 상태에서 표시됩니다.
  • 키보드 입력: 키보드 이벤트를 감시하거나 키 입력, 비밀번호, 입력한 텍스트를 기록하지 않습니다.
  • 권한: 자동 팝업에는 입력 모니터링 권한이 필요합니다. 시스템 설정 > 개인정보 보호 및 보안 > 입력 모니터링에서 허용하거나 철회할 수 있습니다.

4. Finder 연동 및 Apple Events 자동화

사용자가 새 파일 생성을 요청하면 대상 위치를 확인하기 위해 Finder에 Apple Events(com.apple.finder)를 보냅니다. 클릭하거나 선택한 항목의 종류와 경로, 현재 삽입 위치 또는 바탕화면 위치를 조회합니다. 이 Finder 조회는 기존 파일의 내용을 읽거나 분석하지 않습니다. Finder 자동화 권한은 대상 위치 확인에 사용하며, 파일 생성에는 별도로 승인한 폴더 접근 권한을 사용합니다.

5. 샌드박스 파일 생성 및 대상 저장소

LNewFile은 Apple 공식 App Sandbox 및 Security-Scoped Bookmarks 규격에 따라 사용자가 승인한 폴더 내에만 새 서식 파일을 생성합니다:

  • 파일 생성은 사용자의 Mac 로컬 저장 공간에서 직접 수행되며, 파일 경로가 개발자 서버로 전송되지 않습니다.
  • 대상 폴더가 Apple iCloud Drive, 외장 드라이브, 또는 클라우드 동기화 폴더(Dropbox, Google Drive 등)인 경우, 파일 보관 및 네트워크 동기화는 해당 저장소 서비스의 정책에 따릅니다.

6. 서식 템플릿 관리 및 로컬 저장소

사용자 서식, 설정, 폴더 접근 북마크는 Mac의 앱 저장 공간에 보관됩니다. 서식을 추가하면 해당 문서를 앱 저장 공간으로 복사합니다. 앱 삭제 후에도 일부 로컬 데이터가 남을 수 있습니다. 이미 만든 파일은 저장한 폴더에 남으며 Finder에서 직접 관리하거나 삭제할 수 있습니다. 로컬 앱 데이터 삭제 방법은 lmind0179@gmail.com으로 문의할 수 있습니다.

7. 사용자 권한 통제 및 문의 처리

앱에서 사용자 서식과 저장된 폴더 접근 승인을 삭제할 수 있습니다. 입력 모니터링과 Finder 자동화 권한은 시스템 설정 > 개인정보 보호 및 보안에서 철회할 수 있습니다. 개발자는 Mac의 파일에 원격으로 접근하거나 파일을 삭제할 수 없습니다. lmind0179@gmail.com으로 보낸 문의 메일은 답변 목적으로 사용하며, 필요한 동안 보관하고 더 이상 필요하지 않으면 삭제합니다. 문의 메일의 삭제를 이메일로 요청할 수 있습니다.

8. 처리방침 변경 안내

기능 추가나 시스템 변경이 있을 경우, 본 공개 페이지를 통해 개정 사항과 시행일을 안내합니다.
