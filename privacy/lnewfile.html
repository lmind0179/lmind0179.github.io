Privacy Policy for LNewFile

Effective Date: October 5, 2026

This Privacy Policy outlines how LNewFile ("we", "our", or "the App") respects your file system privacy. LNewFile is a native macOS Finder extension utility designed to create new template files seamlessly.

1. No Personal Data or File Tracking

LNewFile does not collect, scan, upload, or transmit personal data or file contents. We do not maintain any external servers, accounts, or telemetry services.

2. FinderSync Extension & Sandboxed File Access

LNewFile operates strictly within the official Apple macOS App Sandbox and FinderSync architecture:

  • The App interacts with Finder only to display the context menu item and create the file requested by you at the specified target folder.
  • Folder access is restricted strictly to directories you actively browse or authorize using Apple's standard Security-Scoped Bookmarks.
  • LNewFile creates empty or template-based files locally on your Mac's storage drive. No file paths, directory hierarchies, or file names are ever transmitted outside your Mac.

3. Template Management & Local Storage

Custom template files and menu ordering configurations are stored entirely inside your Mac user library container (~/Library/Group Containers/). These preferences remain local to your computer.

4. Third-Party Analytics & Network Connections

LNewFile contains zero third-party advertising SDKs, tracking pixels, or diagnostic telemetry frameworks. The extension and main application function completely offline without outgoing network connections.

Questions or Inquiries

LNewFile 개인정보 처리방침

시행일: 2026년 10월 5일

본 개인정보 처리방침은 LNewFile(이하 "앱")이 파일 시스템 프라이버시를 어떻게 보호하는지 설명합니다. LNewFile은 Mac Finder에서 새 서식 파일을 손쉽게 생성할 수 있도록 돕는 macOS 네이티브 확장 유틸리티입니다.

1. 파일 내용 및 개인정보 미수집 원칙

LNewFile은 사용자의 개인정보나 파일 내용, 파일 목록을 수집, 분석, 전송하지 않습니다. 외부 서버나 계정 시스템을 일체 운영하지 않습니다.

2. FinderSync 확장 및 샌드박스 보안 규격 준수

LNewFile은 Apple 공식 App Sandbox 및 FinderSync 아키텍처를 엄격히 준수합니다:

  • 앱은 사용자가 지정한 위치에 요청한 서식 파일을 생성하고 Finder 우클릭 메뉴를 띄우는 용도로만 동작합니다.
  • 폴더 접근은 사용자가 직접 조작 중인 폴더나 Security-Scoped Bookmarks를 통해 허용한 경로로만 엄격히 제한됩니다.
  • 파일 생성은 사용자의 Mac 로컬 디스크 안에서만 발생하며, 어떠한 파일 경로나 디렉토리 구조도 Mac 외부로 전송되지 않습니다.

3. 서식 파일의 로컬 보관

사용자 정의 서식 템플릿과 메뉴 구성 정보는 사용자 Mac 라이브러리 컨테이너(~/Library/Group Containers/) 내에만 안전하게 보관됩니다.

4. 제3자 분석 도구 미포함

LNewFile은 일체의 광고 SDK나 사용자 행동 분석 도구를 포함하지 않으며, 네트워크 연결 없이 오프라인으로만 구동됩니다.
